# O.V.N.I. — Organisme Vivant Numérique Intelligent

> **O.V.N.I.** = **O**rganisme **V**ivant **N**umérique **I**ntelligent.  
> Ce n’est **pas** un « ovni » au sens populaire (objet volant non identifié) :  
> c’est le **nom scientifique du produit** — un individu numérique intelligent et vivant *in silico*.

Un O.V.N.I. a un **cerveau = moteur LIF** (motif connectome ROI), un monde stochastique, une scène Three.js, une **génétique déclarée** et un **cycle de vie**.

Ce n’est **pas** un LLM qui pilote la mouche.

La **voix** (`/voix`, terminal pédagogique) lit la fiche Taxonomie × Motif ROI × Atlas et le `run_card` LIF — voir [`VOIX_CHIMERE.md`](VOIX_CHIMERE.md).

## Échelles neuronales (claim)

| Couche | Ordre de grandeur | Rôle |
|---|---|---|
| Motif LIF (ex. `escape_feed_v1`) | ~11 neurones | Preuve / replay / Methods |
| FlyWire 2024 (cerveau adulte) | ~139 255 | Atlas / nuage 4D pédagogique |
| SNC étendu (cerveau + chaîne) | ~166 000 | Vue SNC complète (UI Lab → Cerveau) |
| Isotropic fractionator 2021 | ~199 000 | Estimation alternative cerveau entier |

Le nuage Three.js affiche des **proxies GPU** pilotés par les `rates_hz` du motif — pas un LIF 1:1 de 140k.

## Cycle de vie

Œuf → larve → nymphe → adulte → sénescence → mort  
API : `POST /ovni/birth`, `POST /ovni/advance`  
UI : Labo → **Vie** → *Faire naître l’OVNI* (utilise le génotype de l’onglet Génétique).
